CONTEXTUALIAÇAO:

uma empresa deseja organizar melhor seus dados de vendas. Atualmente as informaçoes estao dispersas em planilias e nao da um sistema centralizado para consultas rapidas. A direcao decidiu criar um banco de dados relacional para armazenar dados de clientes, produtos e pedidos, permitindo analises mais eficientes e relatoris confiaveis


DESAFIO:

implementar um banco de dados em SQL que atenda ha necessidades da empresa. 
o desafio envolve:

* modelagem das tabelas necessarias ( clientes, produtos, pedidos).
* criacao das tabelas com chaves primarias e estrangeiras.
* inserçao de dados ficticios para simular o funcionamento da loja.
* consulta SQL que respondam as seguntes perguntas:
* quais clientes realizam mais compras?
* qual produtos foi nais vendido no ultimo mes?
* qual o valor total de vendas por cliente
* listar os pedidos que ultrapassam determinado valor,


RESULTADO ESPERADO:

* um banco de dados funcional criado em SQL que podera ser utilizado em aplicaçoes reais.
* compreeender como funciona as relaçoes entre as tabelas de um banco de daods.
* criar scripts de insersao, alteracao e exclusao de dados.
* um conjunto de consultas SQL que respondam as perguntas propostas
* empregar tecnicas de normalizaçao de dados.
