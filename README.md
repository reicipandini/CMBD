** projeto banco de dados de um sistema de vendas **

este projeto foi desenvolvivdo para a criação de um banco de dados relacional
aplicado a um sistema de vendas.

a primeira parte do  projeto contem a representação do modelo do DB atraves de um diagrama de entidade - relcionamento.

criação das tabelas:
  - clientes;
  - compras;
  - fornecedores;
  - pedidos;
  - produtos.

o projeto possui um código fonte devisado e documentado.
